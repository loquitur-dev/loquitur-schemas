# Documentation ownership

This repository documents the `loquitur-schemas` package and nothing else:

- installing the package and validating documents with it;
- the schema families it bundles and the reason-code catalog it ships;
- the compatibility check and the package checks;
- the package boundary and the fixture policy.

It does not document the operation of a service, a website or documentation-site content,
the internals of another implementation, private evidence material, third-party material or
an unpublished repository. The rules the schemas encode belong to the specification in
`loquitur-protocol`; this repository cites them and does not restate them.

How to run the checks is in [`testing.md`](testing.md).
